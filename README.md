# Monarca Fence Services Redesign

Local redesign prototype for Monarca Fence Services.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The current development server uses `http://localhost:4173/`.

## Production check

```bash
npm run build
```

The quote form and guided project assistant prepare a WhatsApp message. No form data is stored by this local prototype.
